# HSVJ Codec Vendor Package

This directory is the single ROM integration source for the HSVJ arm64 RKMPP/FFmpeg runtime.

## Runtime closure

The required vendor libraries are exactly:

```text
libmpp.so
libavcodec.so
libavformat.so
libavutil.so
libswscale.so
libswresample.so
```

The FFmpeg libraries are generated by:

```bash
ANDROID_NDK_HOME=/home/jevin/android-ndk-r26b \
  /mnt/d/HVIDEO/Hplayer/vendor/ffmpeg-rockchip/build_android_rockchip.sh
```

The script removes its owned output before every build and rejects stale MediaCodec, JNI, avdevice, avfilter, or postproc artifacts. RKMPP is mandatory.

## One-to-one integration rule

The following must contain the same six library names:

- `AndroidProductCopyFiles.mk`
- `vendor/etc/public.libraries.txt`
- `sepolicy/file_contexts`
- `vendor/lib64`
- `device/rockchip/rk356x_box/public.libraries.txt` (the six HSVJ entries, in addition to unrelated board entries)

Do not restore the obsolete `librockit.so -> libffmpeg_58.so -> libdrm/OpenSSL` closure. The current engine does not load it.

## APP build

For the ROM-integrated release APK, build without duplicate FFmpeg/RKMPP payloads:

```powershell
.\gradlew.bat :app:externalNativeBuildCleanHw81StableRelease :app:assembleHw81StableRelease -PuseSystemCodecStack=true --no-daemon --stacktrace
```

The APK must remain arm64-only and retain Vulkan, RKMPP, RGA, JPEG, the engine native library, and the mirror library.
