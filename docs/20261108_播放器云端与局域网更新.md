# 播放器云端与局域网 APP 更新

工程：`D:\HVIDEO\Hplayer`。2026-11-08 起的本次正式构建同时检查点歌服务器与云端；旧播放器需要先安装支持此流程的对应硬件正式 APK。

Native 就绪约 8 秒后读取现有配置，`appUpdateEnabled=false` 时跳过全部 APP 自动检查。点歌服务器沿用 `onlineVodHost:9898`；云端沿用 `licenseServerUrl`，空值使用 Native 授权模块的默认地址 `http://60.205.127.117:8080`，不另建配置或复制云端地址常量。地址为空或无效的点歌服务器不阻止云端检查。

APP 两路请求并发开始，分别验证协议后合并候选，选择实际 versionCode 更高的匹配包；同版本优先使用点歌服务器副本。某一路连接失败、无新版、返回异常均不跳过另一路；如果没有候选且有一路失败，则进入重试。系统 ROM 仍由已有签名控制器处理，已提交或交接未完成时暂停 APP 安装。

启动/检查/下载失败每 30 秒重试，一轮最多 5 次；之后以及检查成功无更新时每 30 分钟再次检查。WiFi 或有线 Network 重新连接后约 5 秒重新检查，已有检查或下载安装过程中不重复触发。退出 Activity 时取消定时器、网络监听、检查任务和下载。

检查与下载均逐请求绑定 Android WiFi/Ethernet Network，不更改进程默认网络。沿用已可达网络缓存与联网验证优先级；传输失败尝试另一网络。下载中断时在另一网络从头下载并截断旧文件，不拼接未经验证的内容。仅支持设备实际接入的 WiFi 客户端/有线网络；仅开启供 PAD 连接的热点不代表播放器具有公网出口。

## API 一对一对应

| 调用 | 请求 | 响应/处理 |
| --- | --- | --- |
| 点歌服务器版本检查 | POST `/api/v1/player-updates/check`，仅 `current_version_code/package_name/hardware` | `D:\HVIDEO\Hvideo_server\src\api\player_update_handler.rs`；`{code:0,data:{has_update,...}}` |
| 点歌服务器 APK 下载 | GET `/api/v1/player-updates/files/{sha256}` | 同一处理器返回 APK |
| 云端版本检查 | POST `/api/version/check`，`current_version_code/hardware/signing_sha256`；有值时带 `device_serial/device_fingerprint/device_model` | `D:\HVIDEO\license-server\src\handlers\app_version_handlers.rs`；顶层 `{has_update,...}`，无更新允许只有 `has_update/message` |
| 云端 APK 下载 | GET 云端返回的 HTTP(S) `download_url`，支持绝对/相对地址 | 云端 APK 静态下载；不把其路径强改为局域网文件接口 |
| Java/Native 设备身份 | `HSVJEngine.getAppUpdateDeviceInfo()` ↔ `Java_com_hsvj_engine_HSVJEngine_getAppUpdateDeviceInfo` | 返回 Native 上报所用序列号、型号、硬件指纹和默认云端地址，不受 WiFi/有线 MAC 切换影响 |

本地请求不加入云端专用字段，兼容服务端 `deny_unknown_fields`。云端按实际设备身份筛选全部/代理商/分组/序列号及型号范围。检查时上报当前 APK 证书 SHA256；下载后仍检查文件大小、SHA256、APK 实际包名、versionCode、硬件元数据与完整签名集合，拒绝同版本、降级、错硬件和异签名包。下载重定向、超大内容、截断、哈希不符均失败，不提交安装。

下载暂存至应用专属 Downloads 目录；失败或取消删除当次文件。保留原静默安装、数据保留和渲染恢复流程，无 root 时使用系统安装界面。已删除原 DownloadManager 任务、Cursor 轮询与未用字段，避免检查使用可达网络而下载仍卡在默认网络。

验证脚本：`python scripts/test_app_update.py`，直接编译执行生产 Java 协议、并发选择及传输代码，使用本机真实 HTTP 服务验证请求、下载、断流、哈希和网络路由替身；它不等同于物理 WiFi/网线切换实机验收。构建版本、签名、产物与实机状态见 `records/20261108-cloud-app-update.md`。
