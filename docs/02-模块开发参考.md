模块依赖由 `scripts/check_architecture.py` 从头文件引用重新计算，并与各模块 CMake 尾部的 `Architecture dependency contract` 比较。修改跨模块 include 时必须同步契约。

歌词自动加载顺序为 MKV 内嵌 ASS、歌词目录中的同名 `.ass`、同名 `.ssa`。内嵌轨道优先选默认 ASS 轨道，否则选第一条 ASS；后台使用 FFmpeg 无损提取为内存中的 ASS 文档。读取到首批完整事件就发布累计快照，后续最多每秒发布一次，由引擎线程应用最新快照，避免等待整个网络文件读完才显示开头歌词；只保留一个待应用快照，不累积队列。最终文档仍由 ASS muxer 完整收尾，保持 ReadOrder 与原始时间戳。样式调整从累计原始字幕内容重建，暂停与跳转沿用绑定视频层的播放时钟。读取失败、无轨道、空字幕或超过 30 秒时清除临时字幕并回退目录；切歌取消旧任务并丢弃其结果。读取过程仍需遍历媒体数据，网络文件有额外流量；若跳转到尚未提取的段落，需等后台读到对应字幕。此功能不新增 HTTP API 或歌曲数据库字段。

歌词两行下移至 1080p 基准的 y=860/1010，默认描边为 4；未唱部分黑描边，已唱部分白描边。libass 对歌词背景位图单独标记，GPU 将其合并为覆盖双行的一块黑色背景（约 8% 透明、92% 不透明），使用一个实心纹理像素绘制，避免重复叠加透明度。倒计时直径按字号的 48% 计算（脚本坐标内限制 32–96），再随输出缩放，不从文字或背景位图推测尺寸。Layer 21 的 `fontFile` 沿用现有配置保存链路；字体路径保留到 libass 初始化完成后应用，运行时切换字体会刷新歌词纹理。

歌词渲染的 Android Debug 构建也对 `libass` 和 `hsvj_lyric` 开启 `-O2`。R8 atlas 在当前歌曲内只扩容、不随字宽收缩，最大 2048×2048；更新字幕轨道保留 GPU 分配，重复的累计文档直接复用。CPU 双缓存使用未初始化字节数组后批量清零，避免混合 Debug 构建中 `vector<uint8_t>::resize` 的逐元素构造停顿。Vulkan 字幕上传及实例数据按 in-flight frame 隔离，fence 完成后才复用，并为同帧多次上传保留独立范围；映射保持到扩容或释放。`LyricUploadPerf` 在慢帧时分别报告打包、CPU 填充、比较、映射、复制、提交耗时。`tests/native/embeddedAssTest.cpp` 验证渐进字幕、完整结果与取消；`lyricRenderBenchmark.cpp` 对同一 ASS 和字体比较渲染耗时与像素校验值。

设备 Web 登录：`GET /api/v1/auth/config` 无需认证且禁止缓存，返回 `{ "ok": true, "data": { "localPasswordConfigured": false, "cloudAgentLoginEnabled": true }, "error": null }`。`POST /api/v1/auth/login` 请求为 `{ "username": "admin", "password": "admin*", "loginType": "local" }`；`loginType` 可为 `local` 或 `cloud`，省略时为 `local`。本地默认密码固定为 `admin*`，自定义密码依次读取 ROM 属性 `persist.hsvj.web_password` 和环境变量 `HSVJ_WEB_PASSWORD`。旧的点数密码机制已移除。

云端登录使用配置的 `licenseServerUrl`，空值使用 `http://60.205.127.117:8080`，与 license-tool 保持相同接口：依次调用 `POST /auth/login`（username/password）、`GET /api/agent/info`（Bearer）、`POST /api/agent/device/check`（Bearer 和本机 fingerprint）。只接受 agent/admin 角色，且设备归属及指纹必须匹配。云端密码和令牌仅用于本次验证，不存盘、不返回浏览器；验证成功签发设备本地会话，沿用原有独占登录和退出规则。成功 data 为 `{ "token": "本地会话令牌", "expiresIn": 7200000 }`；错误沿用 `{ "ok": false, "data": null, "error": { "code": "...", "message": "..." } }`，格式错误 400、密码错误 401、角色或归属不符 403、已有用户在线 409、云端限流 429、云端不可用或响应异常 503。

Android 云端认证通过 `callJavaHttpRequestAcrossNetworks` → `HSVJEngine.requestHttpAcrossNetworks` → `PlatformControlGateway` → `CloudAuthTransport` 发出 HTTP(S) 请求。复用设备上报的 Wi-Fi/Ethernet 网络快照和排序，每个连接由 `Network.openConnection` 单独绑定；传输失败才尝试下一网络，收到 HTTP 响应（含密码错误、限流、重定向）即返回，不跨网络重放明确拒绝。内存中只缓存最近可达的 Network，后续请求优先使用；网络断开后重新选择，不绑定整个进程、不改系统路由。连接和读取超时各为 5 秒，响应上限 1 MiB，禁止自动重定向，HTTPS 沿用系统证书校验。非 Android 环境保留原生 HTTP 客户端。

Android 云端素材同步沿用同一组 Wi-Fi/Ethernet 网络候选，但由 `CloudSyncService` 通过 `callJavaHttpRequestAcrossNetworks` 发送同步清单和下载回执，素材文件通过 `callJavaFileDownloadAcrossNetworks` 逐网络流式写入临时文件。当前网络传输失败时才尝试下一网络，文件完整接收后才替换正式素材路径；两条网络均失败时同步失败且不会保留半截文件。非 Android 环境继续使用原生 HTTP 客户端。

`tests/native/cloudAgentAuthTest.cpp` 使用注入响应验证认证与设备归属契约，并以本机 socket 验证 HTTP 状态码、Bearer、Content-Length、分块响应和截断响应；不依赖真实云端账号。

`tests/cloudAuthTransport.test.mjs` 编译并执行 Java 测试，覆盖失败网络回退、HTTP 拒绝停止重试、GET/POST、Bearer、超时配置、响应大小与完整性校验；JNI 回调签名由 `scripts/check_jni_contract.py` 一对一核对。

Web 登录方式在用户切换时保存到浏览器 `localStorage.hvideo_login_type`，只接受 `local` / `cloud`；再次打开或退出登录后恢复上次选择，无记录时默认云端代理商。偏好按浏览器和访问源隔离，退出或会话失效仅清除令牌，不清除此偏好；不保存账号密码，也不新增 API。

歌词层的 libass 资源由 `Mubu::createLayer` 在创建 Layer 21 时按需初始化并注入，统一覆盖启动预创建和运行中新增图层。`Mubu` 先销毁图层再释放 libass；不再依赖启动时 config 是否已有 Layer 21，避免后续启用歌词时渲染器缺少上下文。

`ass_render_frame` / `ASSRenderer::renderFrame` 返回渲染器持有的借用图像链表，调用方不得 `ass_frame_unref`；libass 需要保留上一帧来检测当前帧变化，并在下一次渲染时自行释放。提前释放会产生悬空指针，导致变色位置已经变化却返回 `detectChange=0`，进而重复显示旧 GPU 纹理。`lyricRenderBenchmark.cpp` 同时校验独立帧内容摘要与变化标志，漏报变化时退出失败，防止仅耗时达标却仍丢失歌词更新。

Web「公共配置 → 歌词配置」的「显示歌名、演唱、出品」统一控制 ASS 中三类片头事件。沿用 `GET/POST /api/v1/config.json`，字段 `lyricHeaderVisible` 为布尔值，默认 `false`；缺失或旧配置按关闭处理，POST 非布尔值返回 400。保存后由渲染线程从原始字幕重建轨道，关闭不显示片头，重新开启恢复原内容；配置持久化，适用于内嵌及外部 ASS、卡拉 OK 及听歌模式。

同一页的「显示歌词背景」沿用 `GET/POST /api/v1/config.json`，唯一字段 `lyricBackgroundVisible` 为布尔值，默认 `true`；旧配置缺失时保持显示，POST 非布尔值返回 400。保存后立即生效并持久化，关闭只过滤 ASS 的黑色背景位图，保留歌词文字、双色描边和倒计时；再次开启恢复约 8% 透明度。渲染线程读取原子配置并刷新绘制缓存，因此暂停播放时也能切换，适用于内嵌及外部 ASS、卡拉 OK 及听歌模式。

同一页的「歌词显示」沿用 `GET/POST /api/v1/config.json`，顶层字段 `lyricDisplayMode` 只接受 `"original"`（默认原文）与 `"pinyin"`（带声调的纯拼音），其他值返回 400；此字段与 `layer21.lyricDisplayMode` 的整数播放效果模式属于不同作用域。保存后在渲染线程从原始 ASS 重建轨道，暂停时也立即生效，切回原文恢复原始汉字。`LyricPinyin` 复用仓库自带 pinyin-pro 的字词数据离线转换，词组识别可跨逐字标签，保留原有 `\k/\K/\kf/\ko` 时间标签、英文、标点、换行及绘图；只在重建轨道时转换，不逐帧转换。拼音歌词的默认字号为 90，原文为 150，用户样式覆盖继续有效。适用于内嵌 ASS 与外部 ASS/SSA；烧录在视频画面中的文字需要另配字幕，不能直接改字。词库外的生僻字保留原文，多音字依赖词组词库，不能保证所有歌词语境的读音。更新字词数据运行 `node scripts/generate_lyric_pinyin.mjs`，生成数据包含来源、哈希与 MIT 许可。

### `app/src/main/java/com/hsvj/engine`

- `MainActivity`：Activity/Surface 生命周期和用户可见启动入口，不直接承载更新或平台命令实现。
- `HSVJEngine`：Java 原生接口门面、Native 回调接收和平台操作委托。
- `PlatformControlGateway`：跨进程系统操作唯一入口。
- `DrmKmsRenderService`：`:drmkms` 进程中的直接显示服务。
- `StartupManager`/`StartupExecutor`/`StartupConfig`：启动任务编排。
- `AppUpdateCoordinator`、`update/AppUpdateManager`：应用更新流程与安装实现。
- `resource/*`、`cache/*`：内嵌资源增量释放及 Java 侧缓存。
- `MirrorManager`、`WfdSinkClient`、`airplay/*`、`UsbAdbScreenMirrorClient`：投屏接入。
- `BootReceiver`、`PackageReplacedReceiver`、`WatchdogAlarmReceiver`：系统广播和恢复链路。

### `app/src/main/cpp`

- `jni_interface.cpp`：48 个 Java native 声明对应的 C++ 导出事实源。
- `AirPlayRkmppSession`：AirPlay 数据接入 RKMPP 会话。
- `NativeUsbAdbMirrorClient`：USB/ADB 镜像 Native 客户端。

JNI 新增、删除或改签名时必须同时修改 Java 声明、C++ 导出和 `scripts/check_jni_contract.py` 关注的关键回调；禁止保留第二个别名 JNI。

### 在线点歌结束与空闲续播

点播歌曲自然结束后，播放器使用当前播放绑定的 `queueItemId` 调用点歌服务器的 `/api/v1/rooms/{roomId}/skip`，由服务器下发下一首或 `IDLE` 房态。空闲歌曲打开或解码失败时，播放器按空闲列表继续尝试其他文件；空闲续播不推进服务器点播队列。异步加载空闲列表后必须核对房态，避免覆盖新点播或解除暂停。

## 3. Web 控制端

8080 从 `src/network/web` 加载主控制台、登录、出厂串口和融合校正。8081 从 `src/network/web/mobile` 加载播放、中控和场景页面，并将 `/shared/` 映射到公共文件。桌面与移动控制台通过 `shared/apiClient.js` 处理超时、重试和响应，桌面入口负责注入登录凭证与失效处理。融合校正使用 8081 免登录服务，与控制台共用响应解析和动作构造。各客户端成功时均读取 `data`。

2026-11-01 修复并发保存公共配置时关闭网络 VOD 偶发返回 500：多个配置请求可能同时停止同一个 VOD 同步线程并并发调用 `std::thread::join()`，触发 `thread::join failed: Invalid argument`；同时并发重载 `SystemConfig` 会修改共享 Fusion map，触发 native heap race。WebSocket 与 HTTP VOD 同步客户端分别串行化 `start()` / `stop()` 生命周期操作，`POST /api/v1/config.json` 再串行化完整的保存、重载和运行时应用事务。

Web 源码由 Gradle `copyWeb` 同步到 `app/build/generated/assets/web`。不要在 `app/src/main/assets/web` 维护第二份副本，也不要重新创建 `mobile/modules/modules`。

2026-09-13 修复图层/切片属性面板标题栏宽度自适应：删除按 1440px、768px 视口阈值强制拆行的样式和标签绝对定位，统一使用可换行 Flex 布局。标题、常用/高级标签、操作按钮按面板自身可用宽度排布，空间充足时保持同一行，缩窄时自然换行；长标题可折行。样式缓存版本更新为 `2.79`，本次不涉及 API 变更。

## 5. Shader、ROM 与工具

- `shaders`：Vulkan GLSL 源，顶层 CMake 注册编译清单；运行时 `.spv` 名必须与清单一致。
- `system-integration/hsvj-codec-vendor`：六个 vendor 共享库及 mk/public-libraries/sepolicy 的一对一集成规则。
- `aosp_wfd_sink`：WFD 系统服务交接资料，不属于 APK Java 模块。
- `scripts/check_api_contract.py`：HTTP 后端与 Web/Flutter 字面量调用契约检查。
- `scripts/generate_api_reference.py`：从路由注册生成 API 文档并检查是否漂移。
- `scripts/check_jni_contract.py`：Java/C++ JNI 一一对应检查。
- `scripts/check_architecture.py`：原生依赖、Android 所有权、Shader 产物、退役子系统检查。

## 6. 模块修改规则

1. 新源码必须加入且只加入所属模块的 `CMakeLists.txt`。
2. 跨模块 include 必须反映到模块依赖契约，foundation 不得依赖业务层，utils 只允许 foundation/jsoncpp。
3. HTTP 能力只注册一个公开 method/path；同步调用端、生成 API 文档并执行契约检查。
4. 固定图层只在 `LayerDefinitions.cpp` 定义 ID/类型/默认优先级。
5. Shader 只提交源码，生成的 SPIR-V 和头文件不得入库。
6. 平台操作经 `PlatformControlGateway`，渲染输出经唯一最终帧所有者。
7. 删除实现时同时删除声明、构建项、调用点和过时文档，不保留无发布需求的兼容壳。

## 7. VOD 转发配置（2026-09-16）

入口为播放器 Web「中控配置 → 外设列表 → VOD转发」。`vodMode=1`（本地）或 `2`（在线）显示，`0` 隐藏；两种 VOD 模式共用 `/huoshan/config/peripherals.json` 的 `vod_forward` 对象。已移除旧系统配置字段 `vodPeripheralForwardEnabled` 及旧内嵌卡片。

复用现有接口，不新增路由：

- `POST /api/v1/peripherals/actions/get_config`：请求 `{"peripheral_type":"vod_forward"}`，统一响应 envelope 的 `data` 为配置对象。
- `POST /api/v1/peripherals/actions/set_config`：请求 `peripheral_type` 加完整配置对象；校验后持久化，前端再调用 get_config 校验保存结果。

```json
{"enabled":false,"protocol":"rs485","port":"/dev/ttyS7","baudrate":9600,"rules":[{"event":"Song","field":"categoryCode","value":"11","hex":"AABB01"}]}
```

`protocol` 为 `rs232` / `rs485`，波特率支持 1200、2400、4800、9600、19200、38400、57600、115200；最多128条映射，每条 Hex 为1至1024字节。Web 将数字串口号转换为 `/dev/ttyS<号>`。保存不发送指令；默认禁用、无映射。

| event | field | 含义 |
| --- | --- | --- |
| Song | songNo / categoryCode / lightCode | 歌曲编号、分类码、灯光码 |
| SetLight | scene | 灯光场景 |
| SetEffect | mode | 音效模式 |
| SetAC | power / temp / mode / wind | 空调开关、温度、模式、风速 |

`value` 为精确匹配字符串；布尔开关填写 `true` 或 `false`。歌曲元数据以实际在线消息/本地曲库为准，缺少字段不匹配。在线新播放队列项和本地成功开始歌曲时触发 Song；本地外设 API 转交相应事件，在线由点歌服务器回调转交。所有匹配项按配置顺序通过既有串口写入链路发送，首次发送失败即停止，不自动重发部分写入的指令。关闭 VOD、关闭转发或投屏接管时不发送。在线未匹配的灯光/音效事件保持既有功能按钮处理路径。

回归：`node --experimental-vm-modules --test tests/vodForward.test.mjs`；原生校验：`wsl -e sh /mnt/d/HVIDEO/Hplayer/tests/run_vod_forward.sh`。

2026-10-13 启动无线模式：Web「公共配置 → IP 配置」将调试热点复选框替换为启动无线模式（热点默认 / WiFi）。唯一写入接口为全量 GET/POST `/api/v1/config.json`，顶层字段 `startupWirelessMode` 仅接受 `hotspot` / `wifi`；非法 POST 返回 400，旧配置缺失该字段时默认热点，旧 `debugHotspotEnabled` 字段不再输出或保存。启动模板保留终端本地选择。专用 ROM 的 TvSettings `WirelessBootReceiver` 在 BOOT_COMPLETED 读取 `/huoshan/config/config.json`，WiFi 自动连接已保存的网络，热点沿用 HVIDEO/88888888；开机后手动切换保持有效。保存启动模式仅在重启设备后生效，需要配套更新系统设置组件。
