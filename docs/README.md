## 文档同步规则

- 模块/依赖变化：更新 `02-模块开发参考.md` 并运行 `scripts/check_architecture.py`。
- HTTP 路由变化：运行 `python scripts/generate_api_reference.py`，禁止手改生成路由表。
- JNI 变化：更新两端实现并运行 `scripts/check_jni_contract.py`。
- 构建、端口、固定图层、输出后端变化：同步对应开发文档，不新建阶段性“完成报告”。
