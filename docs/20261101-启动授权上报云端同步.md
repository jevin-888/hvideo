# 启动授权上报云端同步

## 修改内容

- 播放器启动上报协议升级为 `version=2`，从本地授权文件解析并上报开始/到期时间、模块、启用图层、输入通道和商业模式，同时上报授权来源及签名授权文件原文。
- 上报改为异步立即发送，成功后触发一次云端授权拉取，减少本地授权与云端状态的竞争窗口。
- 授权服务器校验上报文件的设备指纹和 HMAC 签名，将有效本地授权保存到设备同步授权表。
- 云端播放器授权解析优先返回较新的本地同步授权；云端之后签发的新授权按签发时间优先，避免旧本地快照覆盖新签发授权。
- 设备心跳不再写入 `devices.license_start/license_expiry`，避免普通启动心跳覆盖云端手工维护的设备期限；首次注册仍保存初始时间供兼容旧管理页使用。

## 协议字段

`device` 新增：`license_content`、`license_modules`、`license_enabled_layers`、`license_input_channel_count`、`license_usage_mode`、`license_source`。
